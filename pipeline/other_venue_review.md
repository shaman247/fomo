## Active-event follow-up (2026-09-09)

“This is Not Not a Drill” (199122) was already assigned to The Walker Loft (7002), at 120 Walker St, 5th Floor. The frontend instead displayed building fallback 2163 and its Other category because its coordinate lookup selected the first co-located venue. The export also included unrelated tenants solely because they shared coordinates with active events.

Location chunks now use event `place_id` membership. The frontend resolves metadata by that same ID, including separate markers for distinct tenants with the same name/coordinates. Unknown IDs cannot borrow a sibling's metadata; legacy events without IDs require an unambiguous name-and-coordinate match. Regression coverage includes phased loading and a stale venue name or rounded coordinate.

The database audit found no published active events assigned to the 18 remaining Other locations. A complete check of all 31,270 locally exported events found zero venue-identity mismatches after the fix and zero events inheriting Other. The recurring membership report now includes `other_findings.active_events` so new activity at a retained catch-all is visible even when its taxonomy is unchanged. These entries require source review, not an automatic category change. Desktop and mobile browser checks confirmed the event popup identifies The Walker Loft, with its fifth-floor address and Event Hall classification. Local build only; not deployed.

## Maintenance and verification
